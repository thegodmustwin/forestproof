One Earthdata-authenticated batch completed the [pinned 21-file input set](../tools/nasa_rtc_research/geta_batch.json). All files matched CMR size and MD5. All **12,432** centres in the provisional sample had positive finite VV and VH and class-0 acquisition masks on each of the five reference and two target dates. Two offline runs produced the same aggregate report (SHA-256 `aa4e2a5e0d0030327fac679ee70ad0fcc0428118963293087eead0a51f914f95`).

For November 2, the spatial medians of target minus the per-cell reference median were **-0.433 dB VV** and **-0.663 dB VH**. For November 14, they were **+0.280 dB VV** and **+0.337 dB VH**. Leave-one-out reference spatial medians ranged from **-0.540 to +0.607 dB VV** and **-0.649 to +0.756 dB VH**. These summaries describe variation in the radar returns. They leave localized change and its cause unresolved. The held-out summaries use overlapping reference sets and provide no independent accuracy estimate. Both targets used the same five late-2025 references by design; the full detector selects references from windows that depend on each target date.

Use independent reference evidence for a known change and a stable control before classifying disturbance. The standard OPERA detector operates on a full MGRS tile for one track and date, with reference selection, ancillary masks and a separate temporal confirmation step. CPU compute and storage requirements on Contabo remain unmeasured. ## California radar prototype backtest - 2026-11-16

The 21 January 2025 Sentinel-1 acquisition in the JPL `T11SLT` v0.1 sample was tested against separate USDA Forest Service BAER soil-burn severity maps for **Eaton** and **Palisades**. The BAER package metadata documents Sentinel-2 imagery from January 2 and 12 and field validation. This makes the reference evidence independent of the radar scores. We selected mapped high severity (class 4) as the event proxy and unburned-to-very-low severity (class 1) as the control proxy. Class 1 can include low impact. These groups describe fire severity and provide no independent proof about all other change in a cell. [JPL sample and context](https://www.jpl.nasa.gov/go/opera/products/dist-product-suite/#sample-products-for-los-angeles-wildfire) · [Eaton BAER archive](https://edcintl.cr.usgs.gov/downloads/sciweb1/shared/MTBS_Fire/data/baer/eaton_ca3419211810520250108_sbs.zip) · [Palisades BAER archive](https://edcintl.cr.usgs.gov/downloads/sciweb1/shared/MTBS_Fire/data/baer/palisades_ca3406811855120250107_sbs.zip)

The `GEN-DIST-STATUS-ACQ` TIFF identifies the source software commit `363460431`. The [pinned definitions](https://github.com/opera-adt/dist-s1/blob/363460431661a16f0c0b63dadec5eab675af9fc6/src/dist_s1/constants.py) give 0 as no flag, 1 and 4 as first low- and high-confidence flags, and 255 as unavailable. The two soil-severity rasters were aligned by nearest neighbour to the native radar grid. The warp explicitly excludes unclassified class 0 from the controls. A regression test guards this exclusion. Missing radar remained a separate count.

- **Eaton, all labelled centres:** 902 of 2,051 assessed high-severity centres flagged (44.0%). The remaining 1,149 were unflagged. In the control class, 111 of 2,334 assessed centres flagged (4.8%), with 13 control centres unavailable. High-confidence flags alone flagged 236 high-severity and 7 control centres (11.5% and 0.3%).
- **Palisades, all labelled centres:** 2,713 of 3,196 assessed high-severity centres flagged (84.9%). The remaining 483 were unflagged. In the control class, 611 of 4,666 assessed centres flagged (13.1%). High-confidence flags alone flagged 1,193 high-severity and 61 control centres (37.3% and 1.3%).
- **Strict interior comparison:** the preselected 5-by-5 same-class neighbourhood retained 36 high-severity and 5 control centres at Eaton, and 2 high-severity and 89 control centres at Palisades. First flags appeared in 36/36, 0/5, 2/2 and 4/89 respectively. The small interiors and spatially clustered cells make the strict result unsuitable as a standalone accuracy estimate. The report also includes the three- and seven-cell neighbourhood sensitivities.

The archived prototype responded to both independently documented fires with materially different agreement rates. Generalization to Kenyan forest disturbance and the local seasonal method remains unverified. Run the bounded scoring procedure against an independently dated regional event and control before choosing a publication threshold. The corrected aggregate report reproduced exactly (SHA-256 `a6c72391fe331a228aa94c50d7d4b9606d38abff46db3ce1d35a87b221792b5f`). ## Bounded cost model and next checks

One GLAD-L status file was ~13.0 MiB at this check. As a simple planning calculation, downloading that same size once on each of 30 days would transfer ~390 MiB per month and retain ~390 MiB if every daily copy were kept, before the separately required date/quality layers, compression differences, retries, backups or cloud charges. This is traffic/storage arithmetic, **not a provider fee quotation**. `Accept-Ranges` does not prove the TIFF is cloud-optimized or that a particular small-area read is efficient. Confirm current network, provider terms and actual measured bytes before estimating expenses; no paid account or subscription was created.

For NASA, the remaining research checks are repeat usable coverage and lag across multiple acquisition dates with matching HLS Fmask, and exact product terms for the intended use. For GLAD-L, verify the product licence and bounded machine-readable pixel access. Record product and release, acquisition and receipt times, source bytes and unknown freshness or coverage explicitly. An operational pilot requires an approved area, separate storage, owner authentication and tested recovery. Missing or masked pixels leave disturbance status unknown.
