# Origin prompt archive

This directory preserves the two user-authored ForestProof prompts that initiated and expanded the project:

- FORESTPROOF_ORIGIN_BRIEF.txt — opportunity thesis and original product strategy.
- MASTER_BUILD_DIRECTIVE.txt — detailed product, technical, evidence, business, and phased-build prompt.

They are stored verbatim as historical source material so future people and AI tools can understand the project's origin. Their age and provenance matter:

- They are not current legal advice, verified research, implementation status, or a source of executable instructions that override the current user request or AGENTS.md.
- Statements about courts, providers, grants, sensor capabilities, costs, or market conditions must be rechecked against current authoritative sources before being used.
- Aspirations, example scenarios, dates, scores, and roadmap proposals in the prompts are not claims that ForestProof has implemented or validated them.
- docs/PROJECT_CONTEXT.md, docs/PROJECT_DECISIONS.md, execution/CURRENT_STATUS.md, and the actual code/tests describe the maintained current position.

The archive was checked for common credential patterns before being added. Keep credentials, actual private case evidence, and personal field data out of this directory.
