# Design reference library

This package contains original instructions informed by the sources below, checked 2026-11-05. It does not redistribute their assets, copy proprietary screens, install hooks or execute third-party launchers. Popularity is not proof of design quality; these are selected references, not a claim to cover or rank all design sources.

## Instructional references
- Anthropic frontend-design: https://github.com/anthropics/skills/tree/main/skills/frontend-design — visual intention and subject-specific composition. Skill license: Apache-2.0 (see its LICENSE.txt).
- Impeccable: https://github.com/pbakaus/impeccable — critique/refinement vocabulary and product/design context. Apache-2.0. Its full package has executable machinery; this package does not install it.
- Vercel Web Interface Guidelines: https://github.com/vercel-labs/web-interface-guidelines — interaction and interface detail, MIT. Do not assume the separate agent-skills wrapper has the same verified license.
- UI/UX Pro Max: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill — optional style taxonomy, MIT. Do not run its broad stack bootstrap to obtain design references.

## Design systems and visual research
- WCAG 2.2: https://www.w3.org/WAI/WCAG22/quickref/ — testable accessibility criteria.
- GOV.UK: https://design-system.service.gov.uk/ — service flows, plain language and accessible components.
- Carbon: https://carbondesignsystem.com/ — product/data-display structure.
- Radix: https://www.radix-ui.com/primitives — interaction primitives where the existing stack benefits.
- Mobbin: https://mobbin.com/ — inspect public examples of product flows.
- Awwwards: https://www.awwwards.com/ — inspect expressive composition and craft.
- Godly: https://godly.website/ — public visual references.
- SiteInspire: https://www.siteinspire.com/ — public composition references.

For galleries, access only what is publicly available or already licensed. Do not bypass paywalls or copy protected assets/layouts verbatim. Extract a decision (hierarchy, rhythm, flow), explain why it serves the current product, and make original work. No subscription is required by these skills.
